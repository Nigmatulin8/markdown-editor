# Markdown Editor

A split-pane Markdown editor with a live preview styled like GitHub.

## Features

- Write Markdown on the left, see the preview on the right
- GitHub Flavored Markdown: tables, task lists, strikethrough, autolinks
- Preview uses GitHub Markdown styles
- Editor and preview scroll together
- The draft is saved in the browser

## Scripts

```bash
pnpm install
pnpm dev
```

| Command | What it does |
| --- | --- |
| `pnpm dev` | Start the dev server |
| `pnpm build` | Typecheck and build for production |
| `pnpm preview` | Serve the production build |
| `pnpm lint` | Run the linter |
